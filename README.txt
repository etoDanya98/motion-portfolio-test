Motion folio — Selected motion

Open index.html in a browser. Keep style.css, app.js, project.js, and the fonts folder alongside it.
No build tools or external libraries are required.

Visual and motion reference: https://moritzpetersen.com/
Typography: Calibre Regular and Medium, sourced from the supplied reference.
The artwork and animation studies are demonstration content created for this project.

Hover, focus, or tap a project to change the monitor preview.
The selection highlight follows a spring slowed by 1.7x, with smooth text color changes. Previews transition smoothly.
The intro and project list reveal in sequence. More expands the biography.
Click a project title, the monitor, or View project to open its detail page. The highlight, title, and preview animate into the new layout. Back and Escape return to the project list. Browser Back and Forward are supported.
Pause stops the artwork animations. Full motion is enabled explicitly; Pause turns off both artwork and interface animations.
On smaller screens, the monitor moves below the project list.

All visible text, metadata, and accessibility labels are in English.
Live site: https://etodanya98.github.io/motion-portfolio-test/
GitHub Pages publishes the root of the main branch.

Direct project links use #project/form, #project/type, and #project/character. Each page includes three animated study panels and a link to the next project.

The Back transition folds the content panels into a layered monitor stack, returns the title to its selected row, and expands the circular back button into the hover highlight. It also works after scrolling the case study.
