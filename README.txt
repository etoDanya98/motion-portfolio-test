Motion folio — тестовая страница проекта

Сайт: https://etodanya98.github.io/motion-portfolio-test/

Откройте index.html в браузере. Сборка и установка библиотек не нужны.
Публикация: GitHub Pages, ветка main, папка /(root).

Оформление вдохновлено структурой страницы
https://archive.animade.tv/work/apple-seollal
Использованы яркая обложка, графитовый фон, кремовая типографика,
крупные медиаблоки и зубчатые границы секций.
Код, иллюстрации и демонстрационная анимация созданы для этого макета.
Материалы и фирменные элементы Animade не используются.

Обложка и три медиаблока содержат SVG/CSS-анимацию, а не видео.
Все сведения о клиенте, агентстве и проекте — заполнители.
Анимации можно приостановить кнопкой в шапке. Нажатие на работу
открывает её увеличенный просмотр; Escape закрывает окно.
На телефоне галерея перестраивается в одну колонку.
При включённой системной настройке уменьшения движения анимация отключена.

Для следующих версий можно заменить демонстрационные композиции
внутри кнопок data-expand на контейнер с video autoplay muted loop playsinline,
добавив poster и оптимизированные MP4/WebM в папку assets.
Обработчик увеличения копирует первый дочерний контейнер кнопки.
