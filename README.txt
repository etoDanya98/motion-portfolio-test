Тестовое моушен-портфолио

Откройте index.html в браузере. Сборка и установка библиотек не нужны.
Страница работает без интернета. Два блока содержат демонстрационную CSS-анимацию,
один — статичную композицию. Это не загруженные видео и не работы владельца портфолио.

Файл можно опубликовать через GitHub Pages из корня ветки main.
Для публикации нужно загрузить содержимое этой папки в отдельный репозиторий,
затем выбрать Settings > Pages > Deploy from a branch > main > /(root).

Все названия, описания и данные клиента в index.html — заполнители.
Для реальных роликов содержимое соответствующего блока .scene можно заменить на:
<video autoplay muted loop playsinline controls poster="assets/poster.jpg" style="width:100%;height:100%;object-fit:cover"><source src="assets/clip.mp4" type="video/mp4"></video>
Если блок с видео должен открываться в модальном окне, при подключении роликов
нужно также обновить обработчик data-expand, который сейчас копирует .scene.
